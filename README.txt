P1S Business Calculator Pro

Mobile-first PWA for a Bambu Lab P1S 3D-printing business.

Preloaded:
- Filament: $15/kg
- Electricity: $0.1128/kWh
- P1S average power: 100 W (editable)

Features:
- 5 products side-by-side
- Etsy, Local and Marketplace channel fee profiles
- Material, electricity, packaging, shipping and labor costs
- Failed-print allowance
- Profit, margin, break-even price
- Price required for minimum margin
- Price required for target profit
- Profit per print hour
- Save locally on phone
- Export/import business settings as JSON
- Installable offline PWA

Host the folder on HTTPS, open it in Chrome on Android, then choose
Install app / Add to Home screen.
